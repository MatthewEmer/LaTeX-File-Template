\section{Choosing your Compiler}

When designing this template, I have exlusively worked in Visual Studio Code, due to its good debugging features, access to the build files, and syntax highlighting. As
such, all the formatting and commands of this template have been extensively tested in this compiler, and as it stands, have not been tested elsewhere. As such, until I
have the opportunity to test this elsewhere, I would suggest using it in Visual Studio Code as well.
