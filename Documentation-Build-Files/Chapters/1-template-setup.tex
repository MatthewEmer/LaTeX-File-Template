\newchapter{Template Setup}

\newsection{Choosing your Compiler}

When designing this template, I have exlusively worked in Visual Studio Code, due to its good debugging features, access to the build files, and syntax highlighting. As
such, all the formatting and commands of this template have been extensively tested in this compiler, and as it stands, have not been tested elsewhere. As such, until I
have the opportunity to test this elsewhere, I would suggest using it in Visual Studio Code as well.

\newsubsection{LaTeX Workshop}

To get \LaTeX\ code compiling in Visual Studio Code, I used the extension \LaTeX\ Workshop \indirectcitation{latex_workshop}. To set this module up, the link in the 
bibliography is to their project page, where they have outlined installation instructions.

\newsubsubsection{Working with GitHub}

I would always advise working with GitHub when writing \LaTeX\ projects as a good method of version control. As such, I have placed a \filename{.gitignore} file into
the template folder which will ignore any/all build files generated by the compiler (tested for \hyperref[subsection:LaTeX Workshop]{LaTeX Workshop}).

\newsubsubsection{Inserting Figures}

If you wish to insert figures/images into your document, then they should be placed in the \filename{Figures} folder. This will allow you to reference them directly
when inserting them into your project (i.e., use \filename{image\_name} rather than \filename{./Figures/image\_name}). For instructions on inserting images into your
project, the command is documented as \comment{INSERT COMMAND}.

\newsubsubsection{Creating a Bibliography}

If you need your project to include a bibliography, then the functionality for this are already in place within the document, but you will need to edit some of the 
source code relevant to it. Instructions for this can be found in \Cref{chapter:The Bibliography}.
