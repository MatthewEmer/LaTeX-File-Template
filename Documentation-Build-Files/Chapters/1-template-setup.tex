\newsection{Choosing your Compiler}

When designing this template, I have exlusively worked in Visual Studio Code, due to its good debugging features, access to the build files, and syntax highlighting. 
As such, all the formatting and commands of this template have been extensively tested in this compiler, and as it stands, have not been tested elsewhere. 
This means that, until I have the opportunity to test this elsewhere, I would suggest using it in Visual Studio Code as well.

\newsubsection{LaTeX Workshop}

To get \LaTeX\ code compiling in Visual Studio Code, I used the extension \LaTeX\ Workshop \indirectcitation{latex_workshop}. 
To set this module up, the link in the bibliography is to their project page, where they have outlined installation instructions.

\newsection{The Template Files}

To reduce the technical understanding required to use this template, I have split the build files across a few folders to hide files that don't need to be edited, or to group those that make logical sense together. 
Below, I have explained these groups and how each file works so that you can understand the workings of the template if you so wish.

\newsubsection{The Main Files}

Outside of the folders, there are three files in the root folder of the template, of these, one is \filename{.gitignore} which is explained in \Cref{subsection:Additional Files} under the heading \textit{Working with Github}. 
The other two files are \filename{file-name.tex} and \filename{file-name.pdf}.

\newsubsubsection{Document Compiler: file-name.tex}

This is the \textit{.tex} file that compiles the template into the output PDF \filename{file-name.pdf}. 
To edit the name of the output PDF, you simply need to rename this file and change the file name in line one of this file.

\separate{5}After reviewing all the \textit{documentclass} types \LaTeX\ provides, I chose to adopt the \textit{report} type with the default font size being 11pts. 
This class gives a good balance between the simplicity of some of the other more basic academic-style templates, and the modularity of some of the classes designed for longer documents. 

This choice is best illustrated by the \textit{Chapter} divider, which lends itself to the file structure of the template, allowing for long documents to be created with clear separation between parts beyond the default sections and their sub-types.

\separate{5}The rest of the file loads the formatting files from \filename{Template-Setup/}, the document content from \filename{Chapters/}, and sets the graphics path for the template. 
As a result, these lines should not be edited unless either labelled as such in the file, or when explicitly mentioned in a release's changelog.

\newsubsubsection{Template Output: file-name.pdf}

This is the output file of the template. 
All of the content added to the various \filename{Chapter/} files will be compiled and placed in here. 
To change the appearance or content of this file, you will need to edit one of the other files making up the template as detailed in the rest of this guide.

\newsubsubsection{Working with GitHub}

I would always advise working with GitHub when writing \LaTeX\ projects as a good method of version control. 
As such, I have placed a \filename{.gitignore} file into the template folder which will ignore any/all build files generated by the compiler (tested for \hyperref[subsection:LaTeX Workshop]{LaTeX Workshop}).

\newsubsubsection{Inserting Figures}

If you wish to insert figures/images into your document, then they should be placed in the \filename{Figures} folder. 
This will allow you to reference them directly when inserting them into your project (i.e., use \filename{image\_name} rather than \filename{Figures/image\_name}). 
For instructions on inserting images into your project, the command is documented as \comment{INSERT COMMAND}.

\newsubsubsection{Creating a Bibliography}

If you need your project to include a bibliography, then the functionality for this are already in place within the document, but you will need to edit some of the source code relevant to it. 
Instructions for this can be found in \Cref{chapter:The Bibliography}.
